Esta pasta contém arquivos CSS reutilizáveis em todo o projeto, como temas e tipografia.

## Arquivos

- `tema.css`: Define variáveis e estilos de tema (claro/escuro).
- `tipografia.css`: Define estilos de fontes e tamanhos padrão.

Utilize estes arquivos importando-os nos seus HTMLs para garantir consistência visual.
