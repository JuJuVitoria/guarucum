# guarucum
Tecnologia que fortalece raízes, autonomia que floresce com respeito. O Guarucum é um sistema de gestão desenvolvido por estudantes de Engenharia de Software da FIAP, com o objetivo de apoiar povos indígenas e comunidades tradicionais no controle de seus estoques, finanças e negócios de forma autônoma e sustentável.

Este é o repositório principal do sistema de gestão Guarucum.

## Estrutura do Projeto

- `compartilhado/`: Recursos compartilhados (CSS, imagens, etc).
- `sistema-gestao/`: Código fonte do sistema de gestão.
- `publico/`: Arquivos públicos como imagens e logos.

## Como rodar

Abra o arquivo `sistema-gestao/dashboard.html` em seu navegador.

## Tecnologias

- HTML5
- CSS3 (modularizado)
- JavaScript (ES Modules)
