Esta pasta contém o código-fonte do site informativo do projeto Guarucum.

## Objetivo

O site informativo apresenta informações institucionais, funcionalidades do sistema, contato e outras informações relevantes para usuários e visitantes.

## Estrutura

- `index.html`: Página principal do site informativo.
- `assets/`: Imagens, CSS e outros recursos utilizados no site.

## Como utilizar

Abra o arquivo `index.html` em seu navegador para visualizar o site informativo.
